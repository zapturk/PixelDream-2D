# Pixel Dream 2D

A 2D game engine built in Go.

## Overview

**Pixel Dream 2D** is being built from the ground up as a modern, lightweight 2D game engine in Go (Golang).

## Status

Currently in early architecture and setup phase. Core engine design and systems will be introduced progressively:
- Windowing & OS abstraction
- 2D Rendering pipeline
- Input management
- Scene and entity hierarchy
- Audio & asset handling
